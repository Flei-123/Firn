# @NAME@

A Firn program on the appkit: automatic updates from the Fleitec store, a
settings file, a log with rotation, crash reports, a single-instance lock and
translated texts -- on Windows, Linux, macOS, OrientOS and Android from one
source.

Generated by `tools/newapp.sh` of the Firn repository. Everything here is
yours to edit.

## Build

    bash build.sh              # Linux, build/@ID@
    bash build-windows.sh      # Windows exe, build/@ID@.exe (cross build)
    bash build-android.sh      # APK, build/@ID@.apk

`FIRN_ROOT` points at the Firn checkout (the generator wrote `@FIRN_ROOT@`).

## Version

One file: `VERSION`. Bump it, build, release. The update client compares
semantic versions (`0.5.6`, `0.6.0-beta.1`); a pre-release sorts before the
release.

## Packages

    bash package.sh                                  # dist/<version>/: .deb, .tar.gz, AppImage/.run,
                                                     # Windows setup.exe + portable zip + NSIS script,
                                                     # manifest.json (SHA-256 + signatures), store-add.sh
    bash package.sh --platforms linux,windows,android --sign-key ~/keys/pack.key

`pack.ini` says what the packages call the program (name, category, icon, Debian
dependencies); `assets/icon.svg` becomes every icon size (.ico, .icns, PNG set,
Android mipmaps). See `docs/PACKAGING.md` of the Firn checkout.

## Release

    bash release.sh                                  # dry run into a throw-away store
    bash release.sh --store-repo /srv/store \
         --platforms linux,windows --notes "what is new"

It builds each platform, publishes the file with orientstore's
`store add-app` (signed catalog, content-addressed file, channel pointer) and
verifies the store. The store's private key never lives in this project: the
store tool reads it from `$ORIENTSTORE_SCHLUESSEL` or from the store
directory. **A real store is only touched with `--store-repo` and a
confirmation** (or `--yes`).

Channels: `--channel beta` publishes to the beta channel; a program follows the
channel in its settings (`update.channel`) or the one it was built with
(`CHANNEL=beta bash build.sh`).

## Where the files go

| what | Linux | Windows | macOS | Android |
|---|---|---|---|---|
| settings (`settings.json`) | `~/.config/@ID@` | `%APPDATA%\@VENDOR@\@ID@` | `~/Library/Application Support/@ID@` | app files dir |
| state, logs, crash reports | `~/.local/state/@ID@` | `%LOCALAPPDATA%\@VENDOR@\@ID@` | `~/Library/...` | app files dir |

`APPKIT_HOME=/some/dir` moves all of it (tests, portable use).

## Files

| file | what |
|---|---|
| `src/main.fi` | start: appinfo, update boot, log, crash marker, single instance, texts, the window, shutdown |
| `src/appspec.fi` | name, id, vendor, store address and key |
| `src/ui.fi` | the window: sidebar, Home, Settings, Updates, About, the update banner |
| `src/locale/*.opmsg` | your own texts (appkit brings its own) |
| `build*.sh`, `release.sh` | build and publish |

Documentation: `docs/APPKIT.md` in the Firn repository.
