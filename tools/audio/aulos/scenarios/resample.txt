# needs tone44.wav
# tol 0.2
# 44.1 kHz source into a 48 kHz engine: Firn = linear interpolation, Aulos = miniaudio resampler (E3).
# The limit is loose on purpose: this scenario MEASURES the difference, it does not claim parity.
rate 48000
bus master
bus sfx master
event tone sfx tone44.wav loop=1
play tone
render 30000
