# tools/aarch64/environment.txt -- cases whose difference is the RUNNER's
# and not the code generator's.
#
# THIS IS NOT AN ALLOWLIST. An entry is only honoured when the probe named
# in the second column has PROVEN the environment fact in this very run,
# with a program that contains no Firn at all. If the probe says the
# environment behaves like Linux, the entry is ignored and the case counts
# as DIFFERENT again. Anything not listed here can never become anything
# but SAME, DIFFERENT or NOT SUPPORTED.
#
# <file>  <probe>  <reason>
tests/1284_std_io_text_owner.fi mmap-address-reuse the case measures a leak by demanding that a freed mapping come back at the SAME address; qemu-user hands out a fresh address every time (tools/aarch64/qemu_mmap_probe.c drifts by tens of megabytes for a plain C program)
tests/2061_std_env_shell.fi foreign-exec the case starts ITSELF as a child (std.process) to control the environment; execve of an aarch64 file needs binfmt_misc on the host, which a plain qemu-user install does not have (tools/aarch64/qemu_exec_probe.c, a C program, shows it). The same std.process code is checked on aarch64 by tests/2062 and tests/2063, which start x86-64 programs
