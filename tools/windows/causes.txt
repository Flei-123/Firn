# tools/windows/causes.txt -- why a case does not behave the same on Windows.
#
# `<glob> <cause>` per line, first match wins. The globs are matched against
# the `why` half of a DIFF line from tools/windows/run.sh. The point of this
# file is that the round can say WHY something does not work rather than
# only how much -- a bare success rate would say much less.
#
# Threads work on Windows since round WIN-THREADS (`CreateThread` behind the
# thread runtime, docs/WINDOWS_THREADS.md). What is left of the "second
# thread of control" is `fork(2)`/`execve(2)`/`wait4(2)`: `CreateProcessW`
# has a different shape and faking it behind the Linux numbers would be a lie.
*700_process_start*	PROCESSES: fork/execve/wait4 answer ENOSYS -- CreateProcessW has another shape
*SKIP*	NO-GPU: Wine here has no OpenGL context and no Vulkan device; the case prints SKIP on Windows by design
