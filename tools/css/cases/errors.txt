#style
// What has to hold here:
//   * `@media` is parsed as an at-rule, but round 60 does not descend into
//     it -- the red therefore does not arrive (documented in ROUND60.md).
//   * an unknown pseudo-class makes the WHOLE rule invalid: no yellow.
//   * a prelude of pure delimiters is not a selector: no cyan.
//   * `p { font-size: 40px` runs on without a closing brace and swallows
//     the following rule -- that is exactly what the standard says, so the
//     margin does NOT arrive. Everything BEFORE it stays valid, which is
//     what the green on the div shows.
//   * `p[ {` at the end opens a bracket that runs to the end of the file.
//     Everything before it stays valid.
4 | color=ff0000ff font-size=40.000 margin=0.000,0.000,0.000,0.000
3 | color=ff008000
#end
