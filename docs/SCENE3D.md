## OVERLAY ALPHA

- All overlay drawing (`ov_text*`, `ov_label*`, `ov_shapes.*`, `ov_px.px_blend`) composites straight-alpha "over" on a destination of ANY alpha (pixel `0xAABBGGRR`).
- Destination alpha 0: result RGB = source RGB, alpha = coverage * colour alpha (no halo, no mixing with black). Opaque destination: unchanged from before (identical path).
- Text: `overlay_new2` enables `fallback.ctx_set_straight(&ctx, true)`. The default of `lib/font/fallback.fi` is unchanged (`straight=false`: destination treated as opaque, alpha forced to 0xFF), so other users of `chain_paint` are unaffected. Bitmap (CBDT) glyphs still write opaque.
- Shadow (`shadow=true`) is black with alpha `colour alpha * 150 / 255`, composited first, then the text; correct on transparent surfaces.
- Transparent clear: `surface.surface_clear(&s, 0)`.
- Label billboard recipe: `surface_new(w, h)` + `surface_clear(&s, 0)`, draw with `ov_text_ex` / `ov_shapes.ov_round_rect` (fill, border) at pixel coordinates (baseline y = top + size), then use the surface as a material texture. The renderer must honour the texture alpha (Material.tex_alpha, renderer worker) and treat texels as straight (non-premultiplied) alpha.
- Pixels with alpha 0 may keep the text RGB (very low coverage); this is intended for filtering without dark fringes.

## TRANSPARENCY SORTING AND PARALLEL SETUP

- **Sort unit**: a node, or all nodes with the same `sort_group >= 0` (`scene.node_set_sort_group(n, g)`, default -1). Concentric or nested glass needs ONE group: no unit order can be right for shells that surround each other.
- **Order**: `render_order` ascending (`scene.node_set_render_order(n, i)`, default 0), then unit far to near, then back faces before front faces, then triangle depth far to near, then triangle id.
- **Unit depth**: centre of the view-depth range (min and max triangle key of the unit), so it does not depend on tessellation density. Ties: larger max depth first, then unit id (the first node index of the unit).
- **Tri fields**: `Tri.group` (unit id), `Tri.order`; `SortItem` carries the unit depth.
- **Parallel setup** (`render_setup`, `render_vertex`, `render_tri`, `render_bins`, `setup_state`): jobs per visible node; phases run on the pool as `parallel_for` over chunks: vertex transform (2048 vertices/chunk), triangle count pass (dry run of clip/cull, 1024 tris/chunk), prefix sum, triangle fill into one array at fixed offsets, per-chunk band counts (4096 tris/chunk), prefix per band and chunk, parallel bin fill and sort item emit, parallel merge sort of the transparent items (index permutation).
- **Determinism**: every phase writes to fixed offsets in node/triangle order, so the image is bit-identical for any thread count (0, 1, 3, 7).
- **Texture alpha**: `Material.tex_alpha` (default false; `material.mat_textured_alpha(tex)`). Texels are 0xAABBGGRR straight alpha; bilinear filtering runs on premultiplied colour (`render_texa`), alpha multiplies the shade alpha, such triangles go to the transparent pass.
- **Bench**: `tools/scene3d/bench.fi` (`--threads N --fps 1 --duration FRAMES`) prints best frame and best setup time in microseconds.

## SHADOWS (shadow.fi, shadow_collect.fi, shadow_fit.fi, shadow_raster.fi, shadow_lookup.fi, shadow_types.fi)
Directional-light shadow maps. Enable per light: `light.light_set_shadow(&l, size, bias, soft)` (sets `l.shadow = true`; defaults size 2048, bias 0.004 world units, soft 1.5 texels). At most 2 lights (first two DIR lights with shadow=true among the first 8) get a map per frame; point lights never cast shadows. `Light.shadow=false` (default) allocates nothing and leaves the image bit-identical.
Switches: `Material.cast_shadow/receive_shadow` (default true), `Material.shadow_strength` (default 0.6), `Node.cast_shadow/receive_shadow` via `scene.node_set_shadow(n, cast, receive)`. A caster needs node AND material cast; a receiver needs node AND material receive.
Per frame: casters come straight from visible scene nodes (world matrix + mesh), the map is an orthographic f32 depth map from the light fitted to the world AABB of all visible mesh nodes (casters + receivers), square, texel-snapped. Rasterisation runs in row bands of 64 map rows via jobs.parallel_for (each task owns its rows, no atomics; threads=0 sequential; result bit-identical for any thread count). Buffers are allocated lazily in `Renderer.shadow`, reused, freed by renderer_free.
Opaque casters (opacity*eff_opacity >= 0.999) write min depth. Translucent casters write a second map: min depth + product of (1 - alpha*shadow_strength) per texel (only light-facing triangles count, so a closed glass body counts once); shadow_strength 0 = no cast. A receiver is attenuated only when it lies behind the translucent layer.
Lookup (render_shade.shade_sample, one line in the lights loop): factor 0..1 scales the light's diffuse and specular, never hemisphere/ambient. Receiver is moved along its normal by 1.5*texel*sin(theta), compared with bias = shadow_bias + texel*tan(theta)*(soft+0.5); PCF = box filter of half-width `soft` texels (clamped 0.5..6) with exact area weights per texel (smooth, no banding); outside the map = lit.
Limits: the map covers the whole scene AABB (a huge ground plane lowers resolution: raise shadow_size or shrink the plane); grazing light shows texel stair-steps at long shadow ends (raise shadow_size/soft); no shadows from point lights; shadows from transparent receivers' own layers are approximate.
Test: tests/6304_scene3d_shadow.fi (96x64, ss=1).

## TONE MAPPING AND MATERIALS

- **Pipeline**: linear scene color (f32) * `Scene.exposure` -> tone map -> average SSAA samples -> sRGB LUT. Tone mapping runs per SSAA sample before averaging (no aliased HDR highlights); the result is per-pixel and bit-identical for any thread count. Overlay is drawn afterwards in sRGB and is untouched.
- **Modes** (`scene.scene_set_tonemap`, module `tonemap`): `TONEMAP_NONE` (default, identical to the old output), `TONEMAP_REINHARD` (x/(1+x)), `TONEMAP_ACES` (Narkowicz fit), `TONEMAP_FILMIC` (Hable, bias 2, white 11.2).
- **Exposure**: `Scene.exposure` (linear factor, default 1.0), `scene.scene_set_exposure_ev(&sc, ev)` sets 2^ev.
- **Shared shading** (`scene.scene_set_share_shading(&sc, true)`, default off = bit-identical to before): with ss > 1, a pixel whose ss*ss samples all hit the same untextured triangle is shaded once at the pixel center (opaque in `render_rows.fi`, transparent in `render_transp.fi`, same rule: all samples covered and passing the depth test); fog and blend stay per sample, edges, textured triangles and partial pixels shade per sample. Bit-identical for every thread count. Demo cold fusion frame 600: 11.3 G -> 4.2 G instructions, images differ only by <= 19 levels in ~60 px.
- **Glass** (`fresnel.glass_alpha`): opacity rises toward the rim by Schlick Fresnel plus a cubic edge term scaled by `Material.rim`; the center stays clear. Reflections are additive and not scaled by opacity.
- **Metal / env** (`envmap`): reflection of the hemisphere with a soft horizon (width grows with roughness), roughness blends toward the hemisphere mean, F0 = base color for metal, rough Schlick, no black without lights.
- **Textures** (`tex.sample`): texel-center bilinear filtering; `material.mat_tiled(m, uv_scale)` sets `tex_repeat` + `uv_scale` (repeat instead of clamp).
- **Fog**: background blends toward the fog color at the horizon (`fogbg`, derived from the camera basis), so far geometry and sky meet without a seam. Only active with `fog.on`.
- **New fields**: Scene `exposure`, `tonemap`; Renderer `exposure`, `tonemap`, `hz_c/hz_x/hz_y` (after `fog_far`); Material `tex_repeat`, `uv_scale` (after `spec`).
- **Showcase**: `tools/scene3d/showcase.fi --still N` (0 none, 1 ACES, 2 none+fog, 3 ACES+fog), test `tests/6305_scene3d_look.fi`.
