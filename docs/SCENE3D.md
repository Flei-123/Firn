## SHADOWS (shadow.fi, shadow_collect.fi, shadow_fit.fi, shadow_raster.fi, shadow_lookup.fi, shadow_types.fi)
Directional-light shadow maps. Enable per light: `light.light_set_shadow(&l, size, bias, soft)` (sets `l.shadow = true`; defaults size 2048, bias 0.004 world units, soft 1.5 texels). At most 2 lights (first two DIR lights with shadow=true among the first 8) get a map per frame; point lights never cast shadows. `Light.shadow=false` (default) allocates nothing and leaves the image bit-identical.
Switches: `Material.cast_shadow/receive_shadow` (default true), `Material.shadow_strength` (default 0.6), `Node.cast_shadow/receive_shadow` via `scene.node_set_shadow(n, cast, receive)`. A caster needs node AND material cast; a receiver needs node AND material receive.
Per frame: casters come straight from visible scene nodes (world matrix + mesh), the map is an orthographic f32 depth map from the light fitted to the world AABB of all visible mesh nodes (casters + receivers), square, texel-snapped. Rasterisation runs in row bands of 64 map rows via jobs.parallel_for (each task owns its rows, no atomics; threads=0 sequential; result bit-identical for any thread count). Buffers are allocated lazily in `Renderer.shadow`, reused, freed by renderer_free.
Opaque casters (opacity*eff_opacity >= 0.999) write min depth. Translucent casters write a second map: min depth + product of (1 - alpha*shadow_strength) per texel (only light-facing triangles count, so a closed glass body counts once); shadow_strength 0 = no cast. A receiver is attenuated only when it lies behind the translucent layer.
Lookup (render_shade.shade_sample, one line in the lights loop): factor 0..1 scales the light's diffuse and specular, never hemisphere/ambient. Receiver is moved along its normal by 1.5*texel*sin(theta), compared with bias = shadow_bias + texel*tan(theta)*(soft+0.5); PCF = box filter of half-width `soft` texels (clamped 0.5..6) with exact area weights per texel (smooth, no banding); outside the map = lit.
Limits: the map covers the whole scene AABB (a huge ground plane lowers resolution: raise shadow_size or shrink the plane); grazing light shows texel stair-steps at long shadow ends (raise shadow_size/soft); no shadows from point lights; shadows from transparent receivers' own layers are approximate.
