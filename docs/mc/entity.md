# mc_entity -- entity tracking

`lib/mc/mc_entity.fi`. Store of every entity the server announced, fed with raw play packet bodies.

```
store_new() / store_free(&s) / store_clear(&s)
entity_on_packet(&s, &ver, id, &body) -> bool   true = was an entity packet (changes applied or counted in s.bad)
store_get(&s, id) -> *mut Entity | 0    store_count(&s)    store_player_count(&s)
store_player_name(&s, hi, lo, &n)       entity_dump(&s, &out)   canonical text (floats as raw IEEE bits)
Entity { id, kind (0 object, 1 living, 2 player), type_id, uuid, x y z (f64 blocks), yaw pitch (degrees), on_ground, vx vy vz, name }
```

* Version modular: wire ids = `mc_sem.SEM_PLAY_S2C_*` (spawn_entity, spawn_entity_living, named_entity_spawn,
  entity_teleport, rel_entity_move, entity_move_look, entity_look, entity_destroy, entity_velocity,
  sync_entity_position, player_info, player_remove); field layouts = `lib/mc/mc_entity_layout.fi`, GENERATED by
  `tools/mcgen/gen_entity.py` (called by `gen_protocol.py --all`) from minecraft-data. Token format: header of gen_entity.py.
* Units: 1.8 position i32 fixed point /32, i8 deltas /32; 1.9+ f64 positions, i16 deltas /4096; angle byte *360/256
  (f32 degrees from 1.21.2 sync_entity_position).
* Player names: `player_info` / `player_remove` are decoded by the generic walker (`mc_schema.walk_values`), so
  1.8 (action mapper) and 1.19.3+ (bitflags, game_profile) need no extra code. Name is copied into the Entity at spawn.
* Hostile input: all reads bounds checked, nothing is applied for a truncated packet, destroy count bounded by octets left,
  store capped (MAX_ENTITIES 1M, MAX_PLAYERS 64k). Entity id -2^31 is a read-failure sentinel.
* Tests: `tests/2760_mc_entity_basic.fi` (1.20.1 + 1.8.9 known answers, hostile input, 5000 entities, tombstones).
