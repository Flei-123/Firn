# mc_stream -- threaded meshing + chunk streaming (lib/mc/mc_stream.fi) -- DRAFT, COMPILES, NOT TESTED YET
Design (all in the file head): render thread owns world + back end; per frame cull (mc_cull) -> cancel stale queued jobs -> pick sections (visible front to back, then nearest pending), snapshot 18^3 on the render thread, `jobs.group_go` one record per job (FIFO + `max_inflight` cap = re-prioritisation) -> workers mesh with a per-thread mesher slot (CAS claim) and compute conn -> render thread uploads within `upload_budget_us` -> draw. Neighbour wait (`nbr_wait` frames), uniform air / enclosed solid sections need no job, `stream_drop_far` unloads far columns.
Open: tests (tests/2771), tools/mc/stream/run.sh, benchmarks (chunks/s with 1/4/8 threads, sections/frame, tris, ms) as `RESULT <key> <value> <unit>`, mc_lod (heightmap LOD) not started, incremental light only idea: propagate block/sky light per section on a queue and remesh only sections whose light changed.
