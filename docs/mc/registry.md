# mc_registry -- blocks, block states, items, entities, biomes (per version, generated)

`lib/mc/mc_registry.fi` (reader, same for every version) + `lib/mc/vNNN/mc_reg_vNNN.fi`
(generated by `tools/mcgen/gen_registry.py` from minecraft-data: a blob and `registry_make()`).
Reached through the version object: `var r = ver.registry_of()`.

```
reg_block_count / reg_state_count(= highest state id + 1) / reg_item_count / reg_entity_count / reg_biome_count
reg_block_of_state(r, state) -> block | -1        binary search, refuses out-of-range ids
reg_block_name / _min_state / _max_state / _default_state / _flags / _hardness_milli / _stack_size
reg_block_by_name(r, ptr, len)                     name without "minecraft:"
reg_prop_count / reg_prop_name / reg_prop_type / reg_prop_values / reg_prop_value_name
reg_state_prop_value(r, state, i) -> value index   mixed radix, LAST property fastest; bool: 0 = true
reg_state_text(r, state, &buf)                     "oak_stairs[facing=north,half=bottom,...]"
reg_item_name / _stack / _by_name,  reg_entity_*,  reg_biome_*  (entities and biomes are dense records:
                                                    ids are not unique in 1.8 - 1.12 data)
reg_fill_opaque(r, table)                          1 byte per state: solid, non-transparent box (for mc_mesh)
```

* Pre-flattening versions (1.8.9, 1.12.2): state = `id << 4 | metadata`, 16 states per block id, no
  properties (a stable cross-version block model needs extra mapping data -- docs/MC-VERSIONS.md).
* Biome ids of chunk sections (1.18+) index the registry the SERVER sends in Join Game; the table
  here only provides the minecraft-data ids.

Tests: `bash tools/mc/run.sh registry` -- for 1.8.9, 1.12.2, 1.16.5, 1.20.1, 1.20.2 every block, ALL
block states with their properties (24135 for 1.20.1), items, entities and biomes print identically
to `minecraft-data` + `prismarine-block` (an independent state decoder); counter-check included.
`tests/2690_mc_registry_basic.fi`: lookups, hostile ids, legacy states, empty registry.
Size: 1.20.1 blob 107 KB, compile of the whole 5-version binary 0.6 s.
