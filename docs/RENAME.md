# Renaming the language

Central name: `brand.toml` (repo root). `compiler/build.rs` turns it into `brand.rs`; `tools/brand.sh` exports it to shell scripts (`BRAND_*`); `lib/toolchain/tcbrand.fi` is generated by `tools/brand.sh --emit-fi`.
User-visible texts of the compiler (usage, version, lexer hints, C header, wasm runtime messages) and the installer (`firn` command) read these values. Internal identifiers (module paths, `FIRN_*` variables, `__firn_*` symbols, file names) are NOT variable.

Full rename: `python3 -I tools/rename/rename.py --from firn --to NEW` (dry run with report), add `--apply` to change a clean git tree, `--keep-aliases` to accept old `FIRN_*` variables and `firn.package`/`firn.lock` (written to the `[legacy]` section of `brand.toml`; applied by `compiler/src/brand_compat.rs` and the installer).

Handled: all spellings (`firn`, `Firn`, `FIRN`, `firnc`, `__firn_`, `FIRN_`), file and directory names via `git mv`, symlink targets. Left alone: binary files, odd-case spellings (reported), untracked files, `.git`. Edge cases (name inside longer words) are listed and renamed.
Check: `bash tools/rename/check.sh [NEW]` renames in a temporary worktree and back again and expects an identical tree.
Not covered: `/root/certus`, `/root/firnc-gc` (separate repos), the selfhosted `firnc1` does not read the `[legacy]` aliases.
