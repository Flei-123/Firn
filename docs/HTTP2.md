# HTTP/2 client (lib/net/h2.fi)

Blocking HTTP/2 client with multiplexed streams. RFC 9113 + RFC 7541.

## Modules
- `net/hpack.fi` HPACK encoder/decoder (static + dynamic table, Huffman, never-indexed secrets). Tables in `net/hpacktab.fi` (generated by `tools/h2/gen_hpack_tab.py`).
- `net/h2frame.fi` frame constants, header codec, padding.
- `net/h2.fi` connection: SETTINGS, flow control (connection + stream, 1 MiB receive windows), CONTINUATION, PING, GOAWAY, RST_STREAM.
- `tls/tls.fi`: `tls_offer_h2(t, true)` offers `h2` then `http/1.1` in ALPN; `tls_alpn_is_h2(t)` tells the result.

## Use
```
import net.h2
var c: h2.H2 = h2.h2_new()
h2.h2_connect_tls(&c, addr, 443, "host", roots_ptr, roots_len, now)
let id: i32 = h2.h2_request(&c, "GET", "https", "host", "/", "accept: */*\n", 0, 0)
h2.h2_wait(&c, id as u32)
h2.h2_status(&c, id as u32)
h2.h2_body(&c, id as u32)
h2.h2_release(&c, id as u32)
```
`h2_connect_plain` speaks h2c with prior knowledge. Up to 16 streams in flight (`MAX_STREAMS`); start several requests, then wait for each. Response headers are length-prefixed records read with `hpack.hdr_next` / `hpack.hdr_find`.

## Not included
- Server side (`lib/http/server.fi` still answers HTTP/1.1 only).
- Server push (disabled via SETTINGS_ENABLE_PUSH=0, PUSH_PROMISE is a protocol error).
- Stream priorities (ignored), trailers (decoded, dropped), request header size limits beyond `max_list` 256 KiB.

## Tests
`heavy bash tools/h2/run.sh`: HPACK cross-check against Python `hpack` (encode + decode, 900 blocks), HPACK fuzz (1500 mutated streams), frame fuzz against a hostile server (400 runs), end-to-end against Python `h2` server (h2c and TLS+ALPN): GET, 404, extra headers, 300 KB upload with flow control, 3 MB download, 36 KB header block with CONTINUATION, PING, 40 sequential requests.
