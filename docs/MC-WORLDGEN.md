# MC-WORLDGEN -- version neutral worldgen core + version data

State 31.10.2026. Plan and measured status. Rule: version = data (datapack JSON per version, generated by the jar's datagen), engine = neutral Firn code.

## Pipeline stages
1. Biome source (multi_noise climate: temperature, vegetation, continents, erosion, depth, ridges from the noise router)
2. Noise router / density functions -> `final_density` (terrain), aquifer + vein inputs
3. Noise chunk fill: cell interpolation (interpolated markers), flat caches, aquifer (water/lava/air), ore veins
4. Surface rules (noise_settings.surface_rule, 1.20.1) / material rules (26.3)
5. Carvers (caves, canyons), features (placed_feature by decoration step), structures (structure_set, template pools)
6. Lighting

## Neutral core (Firn, lib/mc/gen) vs per-version data
| Neutral | Per version (tools/mcgen/worldgen/<ver>/) |
|---|---|
| RNG (legacy, xoroshiro, positional), noises (improved, perlin, normal, blended, simplex) | noise/*.json (octaves, amplitudes) |
| density function loader + interpreter (wgdf_*), op registry by type name | density_function/**/*.json, noise_settings/*.json (router, sea level, cell sizes) |
| cubic spline (float math as in Java) | spline points inside density functions |
| chunk fill loop, flat cache, interpolators (next) | surface rules, biomes, features, structures (next stages) |

## Measured findings (31.10.)
- Datagen: `java -DbundlerMainClass=net.minecraft.data.Main -jar server-<ver>.jar --server --reports --output <dir>` (jdk25 for all jars). Data copied to tools/mcgen/worldgen/{1.20.1,26.1,26.3} (density_function, noise, noise_settings).
- 1.20.1 and 26.1 share the engine API (RandomState.create(provider, key, seed), router(), finalDensity()). The SAME interpreter is bit-identical for both (1.20.1 overworld/amplified/large_biomes, 26.1 overworld).
- 26.1 vs 1.20.1 data: 35 density functions each, 60 vs 62 noises, many density/noise files differ (terrain shaper splines).
- 26.3 is an ENGINE change, not only data: RandomState.create(HolderGetter<NormalNoise>, long, NoiseGeneratorSettings), DensitySampler / DensityBufferPool / MaterialSystem, `float sampleBlockValueUncached`, noise_settings.router has chunkSurfaceLevel, 55 density functions (new: final_density, chunk_surface_level, preliminary_surface_level, temperature, vegetation, ore_vein/*, end/islands), new worldgen dirs (material_rule, material_condition, block_state_provider, feature, carver). Needs its own oracle API (tools/mc/wgen/oracle/v26_3) and a float-precision check before the interpreter is trusted there.
