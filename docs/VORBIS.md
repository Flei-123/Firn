# Ogg Vorbis in Firn (`ton.ogg`, `ton.vorbis`, `ton.vorbis_file`, `audio.load_ogg`)

Pure Firn, no C. Files: `lib/ton/ogg.fi` (container), `lib/ton/vorbis.fi` (decoder, packets in, PCM out),
`lib/ton/vorbis_tab.fi` (floor1 dB table, generated by `tools/vorbis/gen_tab.py`), `lib/ton/vorbis_file.fi`
(whole file -> PCM), `lib/audio/load_ogg.fi` (sample for `audio.engine`; `.ogg` also in `audio.bank`).

## Use
```
import ton.vorbis_file
var pcm: rt.Buf = rt.buf_new()
var info: vorbis_file.VfInfo = vorbis_file.vf_info()
let st: i32 = vorbis_file.vf_decode_f32(ptr, len, &pcm, &info)   // or vf_decode_i16; 0 = ok
// info.rate, info.channels, info.frames, info.bad_packets; pcm = interleaved
```
Engine: `load_ogg.ogg_load(&e, ptr, len)` -> sample id or -1 (max. 2 channels, linear resample to the engine rate).
Packet level API (headers, `vorbis_decode`, `vorbis_to_i16/f32`) is described at the top of `lib/ton/vorbis.fi`.

## What is in / not in
- In: all Vorbis I streams with floor 1 (all libvorbis / ffmpeg output), residue 0/1/2, coupling, 1..255 channels,
  both block sizes 64..8192, codebook lookup 1/2. Final length trimmed to the last page's granule position.
- Not in: floor 0 (error -5; no encoder writes it), seeking, chained links in `vorbis_file` (only the first logical
  stream; `ogg_next_link` exists), Ogg Skeleton.

## Accuracy (vs libsndfile, f32 output)
Method: `tools/vorbis/compare.py`, 8 files (mono/stereo/3ch/5.1, 8-48 kHz, q-1..q10, impulse, pink/white/brown noise,
60 s stereo). Frame counts equal, **max deviation 0.0010 - 0.0117 LSB of 16 bit** (RMS 4e-9 - 3e-8): float rounding
(same f32 algorithm, different IMDCT), not bit-exact by design. `tools/vorbis/run.sh` demands <= 1 LSB.

## Speed (60 s stereo 44.1 kHz noise, q5, this machine)
dev 15.3 s (4x real time) - default 1.8 s (33x) - release-safe 0.40 s (150x) - release-fast 0.25 s (240x).
libsndfile (C): ~0.13 s incl. Python call. All levels give identical output bytes.

## Robustness
Every bit read is bounds-checked, stream-controlled indices are validated at setup or clamped, setup memory has a budget.
Fuzz (`tools/vorbis/fuzz.py`: truncation, bit flips, byte overwrite, cut-outs, header damage; CRCs repaired so the damage
reaches the decoder): **8600 runs (dev 600, release-safe 8000), 0 crashes, 0 hangs**; result is either PCM or a clean
error code (-1 malformed, -2 header packet, -3 not ready, -4 memory, -5 floor 0). A damaged audio packet is skipped
(`bad_packets`).
