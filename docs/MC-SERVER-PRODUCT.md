# Firn Minecraft dedicated server (firnmc-server)

## Ist-Zustand (before)
- `demos/mcsrv`: test CLI (`--port --view --mode --world --ops --ticks`), flat world or saved vanilla world, no config file, no console, binds 127.0.0.1.
- `sv_host` runs the server thread (`lib/mc/server/*`), `sv_persist*` saves edits/players/level clock into an existing vanilla world, `sv_ops` reads `Name:level,Name` from the config.
- Gaps: server.properties, bind address, whitelist, ops file, stdin console, signals, vanilla log format, headless packaging.

## Product
- Binary `firnmc-server` (`demos/firnmc-server/main.fi`, modules `lib/mc/dedi/*`). Static Linux x86_64 ELF (no libc, no Java), Windows exe builds too (`--target=x86_64-windows`, signals are no-ops there, `stop` works).
- Args: `nogui` (ignored), `--dir DIR` (file root, default cwd), `--port N` (overrides server-port), `--world DIR` (overrides level-name).
- Minimal server edits: `sv_host.host_start_cfg(.., setup)` hook, `Config.whitelist_on/whitelist/quiet_joins`, whitelist check in `sv_login`, `sv_whitelist.fi`.

## server.properties
- Created on first start with vanilla 1.20.1 key names (`dd_defaults.fi`); missing keys are added, unknown keys and comments are kept verbatim.
- Applied: `server-port`, `server-ip` (empty = 0.0.0.0), `motd`, `max-players` (cap 32), `gamemode`, `view-distance` (2..32), `network-compression-threshold`, `level-name`, `white-list`, `enforce-whitelist`, `op-permission-level` (level given by `op`).
- `online-mode=true`: parsed, warning, server runs offline (no auth yet). Default written is `false`.
- Parsed, not yet applied: `difficulty`, `hardcore`, `pvp`, `allow-flight`, `enable-command-block`, `spawn-protection`, `simulation-distance`, `level-seed`, `level-type`, `generate-structures`, `force-gamemode`, `enable-status`, `hide-online-players`, `max-tick-time`, `player-idle-timeout`, `rate-limit`, rcon/query keys, resource-pack keys, `allow-nether`, spawn-* keys, `entity-broadcast-range-percentage`, `function-permission-level`. Java escapes (`\uXXXX`) in values are not decoded.
- World: `<level-name>/level.dat` must exist (vanilla world). Missing = non-persistent superflat world and a WARN line (world creation is a roadmap item).

## Console (stdin, Pterodactyl)
- Commands without `/`: `help list say op deop kick whitelist(on|off|add|remove|list|reload) save-all time(set|add|query) tps version stop`. Unknown: `Unknown or incomplete command, see below for error`.
- Missing standard commands (roadmap): gamemode, tp, difficulty, defaultgamemode, ban/pardon/ban-ip, banlist, kill, give, weather, seed, setworldspawn, gamerule, tell/msg, whitelist from properties write-back, save-on/off, rcon.
- `stop`, SIGTERM and SIGINT: save world (players, chunks, clock), exit code 0. Port in use / world unreadable: exit code 1.
- `ops.json` / `whitelist.json` in vanilla layout (offline UUIDs), loaded at start, written on change. Not handled: `ops.json` `bypassesPlayerLimit`, whitelist names are case-insensitive.

## Log
- stdout and `logs/latest.log` (truncated per start): `[HH:MM:SS INFO]: text` (also WARN/ERROR).
- Ready line: `[HH:MM:SS INFO]: Done (0.004s)! For help, type "help"`; also `Name joined the game` / `Name left the game`.

## Pterodactyl
- Egg: `deploy/pterodactyl/egg-firn-minecraft-server.json` (PTDL_v2, generated by `tools/mc/dedi/make_egg.py` from `deploy/pterodactyl/install.sh`).
- Image `ghcr.io/pterodactyl/yolks:debian`; startup `./{{BINARY_FILE}} nogui --port {{SERVER_PORT}}`; done `Done (`; stop `stop`; `server.properties` parser sets server-ip, ports, motd, max-players, view-distance, level-name, white-list from variables.
- Installer (alpine installer image): downloads `$FIRN_RELEASE_URL/firnmc-server-linux-x86_64`, verifies `SHA256SUMS`, keeps worlds on reinstall.
- Binary hosting: `https://store.fleitec.com/firnmc-server/latest/` (files in `/srv/store/firnmc-server/` on the JARVIS server, served by the public openresty). Publish with `bash tools/mc/dedi/release.sh`.

## Tests
- `bash tools/mc/dedi/run.sh`: start, properties, ping, console, join/leave, whitelist, ops, kick, stop/SIGTERM exit 0, saved world, port conflict.
- `bash tools/mc/dedi/egg_run.sh`: egg structure, installer (checksum ok/bad/unreachable), Wings-style properties edit, clean-env start, `stop`.
- Regression: `bash tools/mc/server/run.sh` (integrated server gate A-J).
